## 1. 项目目标与统一方法

论文暂定标题：**Hard-Constrained Generative Neural Fields**。

我们研究的问题是：给生成模型指定一些必须满足的点值、导数或结构要求，让不同随机样本都满足这些要求，同时允许未被约束的部分产生合理变化。

统一链路：

```text
上下文 + 随机变量 + 测试时给定的要求
                     ↓
                生成连续场
                     ↓
          CNF 约束表示层 / 采样过程接入
                     ↓
        满足要求的多样场 + 对应应用输出
```

例如：同一组表面点对应多个完整形状；同一组动作关键帧对应多条中间路径；同一组形变 handle 对应不同未固定区域的形变。

各应用可以使用不同生成先验、网络权重和数据集。共享的是场接口、约束算子、求解器、生成接入机制与评测原则。

**保证范围必须明确：** 有限点上的精确约束，不自动推出全域物理有效、拓扑正确、像素精确或真实执行成功。测量噪声、不可行目标、秩不足和数值误差都应显式处理。

## 3. Application A：视频世界建模

**英文名称：Video World Modeling with Constrained Motion Fields**。

**范围决定（2026-11-13）**：按用户决定，将视频/world-model 应用收敛到 input-level。统一叙事是生成 motion/neural-field representation → CNF 在该表示上施加有限维线性约束 → render control → 以 control 条件驱动预训练视频模型。CNF 的既有解析修正公式不是新贡献；保证只涉及适用相容条件下实际约束的表示/算子，生成 RGB 的跟随属于测得效果。

最新证据位于研究工作区 `cvpr2027/`，不是新仓库内的运行依赖：`docs/input_level_independent_audit_20261113.md`、`docs/clearance_feasibility_20261113.md`、`docs/motion_conditioning_ablation_20261113.md`。前两份决定当前 input-level 结论与可行性前置条件；第三份记录已完成的 latent 相关下游探索。代码、模型和历史结果全部保留。

### A1. Input level：以 1.3B 模型结果为准

**2026-11-14 最新已完成结果（v2）：** 固定基／学习基 × Soft／Hybrid，16 scene × 2 motion seeds × 2 Wan seeds，共 128 条动作、256 条视频及完整评分。使用相容 v2 参考、共享安全要求和保锚点修正；两组 Hybrid 最终锚点最大误差均为 `8.882e-16 rad`。同基内 Soft／Hybrid 的 checkpoint 和实际噪声配对已核验。

学习基组视频锚点 EPE `4.412→1.947 px`（−55.9%），PSNR `22.386→22.588 dB`；两项场景配对区间均支持改善。固定基也有同方向收益，学习基相对固定基暂无显著额外收益。本轮未使用 GT 速度，未添加导数硬条件；Soft 指同一先验下关闭采样硬投影，两组训练仍含共同的生成与辅助场损失。

最新证据位于研究工作区 `docs/world_model_input_level_research_report_20261114.md`、`docs/learned_basis_hybrid_psnr_20261114.md`、`docs/learned_basis_hybrid_acceptance_20261114.md`，以及 `experiments/cnf_pickplace/outputs/learned_basis_hybrid_cnf_20261114/`。RGB 遵从性、模拟器域分割器校准及单训练 seed 的解释范围见这些报告。

**以下 A1 内容为 2026-11-13 的历史配置、结论与当时待办。** 锚点／clearance 冲突、单 Wan seed、8 scene 等描述仅限该旧协议；v2 已完成可行性修正和上述矩阵，不应继续将这些历史前置任务列作本轮未完成工作。生成域人工标注、多训练 seed 与执行证据仍需独立补充。

目标：在相容条件下约束运动场，再通过视频模型的输入控制接口生成相应视频，并独立测量 RGB 跟随。

```text

                 ↓
         生成运动表示并施加 CNF 约束
                 ↓
      segmentation control video
                 ↓
   Wan2.1-Fun-V1.1-1.3B-Control + LoRA
                 ↓
              RGB 视频
```

**当前能支持的结论**

- **Control 通路有因果作用**：固定首帧、Wan seed43、prompt 与 LoRA，8 scene 的冻结 control 干预使 HSV cube 跟随 EPE 为 `0.427 px`，原 moving GT replay 对同一静止目标为 `34.566 px`；8/8 改善。GT replay 8/8 逐像素一致。支持该设置下的条件控制与二维 cube 跟随。
- **同 prior 投影有稀疏位置增益**：`hybrid_anchor` 与 soft 使用同一 soft prior、同一初始 noise `5000+i`、相同六 anchors，无额外 GT 速度，唯一额外操作是逐步 anchor 投影；所有方法做相同 clearance。HSV anchor video→GT 均值 `3.378→2.011 px`，配对 Δ=`−1.367 px`，95% CI `[-2.113,-0.622]`，8/8 改善。该证据是二维位置代理增益，不是 RGB 关节/速度硬满足。
- **没有全面质量优势**：上述同 prior 对比 PSNR Δ=`−0.087 dB`，全帧 HSV video→GT Δ=`+0.104 px`，CI 均包含 0；全帧/control 跟随也未稳定改善。稀疏 anchor、nonanchor 和 GT 还原回答不同问题。
- **当前联合条件不可行**：8/8 scene 的固定 GT 锚点 4/12/13 帧 EE 高度约 `.3650 m`，与 `safe_z=.3655 m` 冲突（24/48 anchors）。纯 anchor 投影约 `3e-7 rad`，后续 clearance 使最终锚点误差约 `0.0013 rad`；保持固定锚点的 nullspace 修正无法消除该冲突，不能宣称最终整条轨迹严格可行。

证据仅覆盖 8 scene、单 Wan seed43、同一合成生成器和 oracle anchors；HSV tracker 未独立标注校准，多项 CI 未做多重比较校正。冻结干预与位置代理不能证明 7DOF pose、速度、真实接触/碰撞或 RGB 硬约束，也不能外推为真实场景或多 seed 稳健优势。

### A2. Latent level：deferred / exploratory，保留历史

此路线不进入当前主贡献或待办，不继续扩展模型/训练矩阵；既有 Cosmos 2B、scratch U-Net 代码、模型、配置与结果保留。该范围决定不等于宣称 latent 接入普遍不可能。历史小模型中 latent 指运动系数 `c`，约束后转成 `q(t)` 输入视频网络，不是在 Wan/Cosmos VAE/DiT latent 上获得硬保证。

## 4. Application B：受约束动作生成

**英文名称：Constrained Action Generation**。

**2026-11-14 应用定位补充：Agent 可调用的 action chunk 技能。** Agent 给出稀疏关键姿态，技能保留生成先验与 CNF，先产生连续动作场，再按控制频率查询为稠密 chunk。第一版沿用固定六个、七维关节姿态锚点；可变数量／时刻、末端空间要求与导数条件需适配和验证。

已有动作场数值验证与视频应用结果可作为技术基础，但 skill 封装及“Agent—技能—控制执行—新观测”的闭环尚未实现／评测，不能用控制视频渲染代替执行成功率。下列 DROID 等历史导数设置与本轮零阶姿态锚点实验分别引用。

### 任务定义

输入初始关节状态、稀疏 waypoint 以及可靠的速度等要求，生成多条满足要求的连续关节目标轨迹。未固定的中间路径、冗余姿态可以变化。

## 5. Application C：3D 形状补全

**英文名称：Hard-Constrained 3D Shape Completion**。

### 任务定义

输入部分表面点和可信法线/梯度，生成多个合理的完整 3D 隐式表面。给定位置的局部要求固定，未观测部分允许变化。

约束例子：`f(p_i)=0`、`∇f(p_i)=n_i`。后者同时指定梯度方向与尺度；若只有方向信息，需要另行定义相应约束。

### 当前完成情况

该模块以官方 SDFusion 为生成先验，用 Hermite-Gaussian CNF 在 32 个观测表面点施加 128 条点值和梯度等式。提供 Plain、Soft 和 CNF 三组训练，以及六组留出评测。代码已通过离线 CPU 回归和 A100 预检，已有单类别、单视角条件下的留出评测。 [形状补全运行说明](../tasks/shape_completion/README.md)

### 待合作者完成

1. 扩展到多视角、其他类别和真实扫描。
2. 测试改变锚点数量和位置、重复锚点及冲突约束时的求解行为。
3. 在同一组稀疏条件下生成多个完整形状，评估多样性与推理成本。

**验收**：指定点值/梯度达到预先冻结的数值容差；未知区域存在有效变化；没有用增加伪影来换取多样性；不可行或病态系统有明确诊断。

**保证边界**：局部表面/梯度约束不保证全域 SDF、固定拓扑，也不保证有限点之间的整个已知曲面片保持不变。网格提取误差单独报告。

## 6. Application D：形变场生成

**英文名称：Hard-Constrained Deformation Field Generation**。

### 任务定义

生成位移场 `u(x)`，变形后位置为 `T(x)=x+u(x)`。要求固定 handle 不动，或指定 handle 位移；其余区域产生不同合理形变。

约束例子：`u(p_i)=0`、`u(p_i)=d_i`，以及指定的局部 Jacobian 分量。

### 当前完成情况

已完成方向、目录与任务定义，**尚无数据、先验接入或实验结果**。可以由熟悉几何处理、动画或物理形变的合作者独立认领。

### 待合作者完成

1. 选定一个形变数据/生成先验，说明多样性来自哪些未确定因素。
2. 定义 handle 位置、位移单位和可信度，接入统一 CNF 求解器。
3. 比较无约束、软约束、最终修正与适用的采样期修正。
4. 评测 handle/导数残差、未固定区域的质量、有效多样性、翻折率及推理成本。

**验收**：同一 handle 条件下能生成多个有效形变；固定/位移要求达到预先冻结容差；导数通过独立验证；失败与翻折样本完整报告。

**保证边界**：固定 handle 采样点不等于连续区域固定。正 Jacobian determinant、局部刚性、体积保持属于额外要求，不能自动归入点位移保证。如果完整物理条件唯一决定形变，需要明确哪些条件仍有不确定性。

## 7. Application E：流体场生成

**英文名称：Observation-Constrained Divergence-Free Flow Generation**。

### 任务定义

生成速度场 `v(x,t)`，保留无散度等结构，并同时满足测试时给定的速度观测；其余未观测区域的可行流动可以变化。

建议从具有结构保证的二维流函数表示开始：`v=(∂ψ/∂y, −∂ψ/∂x)`，再接入点速度要求。新增 CNF 修正也必须处在对应的无散度表示空间中。

### 当前完成情况

已完成方向、目录与任务定义，**尚无应用实现或结果**。已有文献包含结构无散度生成，因此本方向应研究“已有结构 + 测试时新增观测”的组合能力。

### 待合作者完成

1. 明确二维/三维、域、边界与速度单位，选择可复现数据及生成先验，核对相关基线。
2. 在不破坏结构性质的前提下接入位置和数量可变的点速度观测。
3. 对不相容的速度/边界目标返回诊断；有噪声的测量不默认全部硬拟合。
4. 同时评估观测残差、无散度结构、边界误差、能谱/场质量、多样性与成本。

**验收**：新增观测满足指定容差，原结构仍成立；与直接输出修正及适用强基线比较；记录全部失败。对全域结构给出表示依据，对数值评估说明微分/差分方法。

**保证边界**：在有限点满足无散度或边界要求，不推出整个连续域或整条边界成立。三维向量势表示还需考虑域拓扑、边界条件和覆盖范围。

## 8. Application F：PDE 场生成

**英文名称：Boundary-Constrained PDE Field Generation**。

### 任务定义

生成连续物理场，满足给定初始条件、边界要求或适当的线性积分守恒约束，并对剩余不确定部分进行多样生成。

### 当前完成情况

已完成方向、目录与任务定义，**尚未选定具体 PDE、数据或生成先验，也无应用实验**。

### 待合作者完成

1. 选定一个规模可控的任务，并说明多样性来源：未知系数、随机外力、缺失条件或逆问题歧义等。
2. 明确哪些要求通过参数化或有限 CNF 系统严格满足，哪些是采样点约束，哪些仅以 residual 衡量。
3. 接入初边值或线性守恒算子，独立验证求积/微分与求解误差。
4. 与适用的无约束、软引导、修正式生成方法比较，分别报告 IC/BC 精度、PDE residual、分布质量、多样性与成本。

**验收**：约束对象和保证范围明确；完整生成评测可复现；不能用初边值满足代替控制方程满足，也不能把有限 collocation 当作全域证明。

**保证边界**：完整非线性 PDE 不由当前线性 CNF 公式直接保证。对唯一解的确定性问题，不能在所有条件固定后仍凭空要求多个不同正确解。

## 10. 共用开发与实验要求

### 模块边界

- 共享 core 放在 `src/gcnf/`；各应用放在 `tasks/<application>/`。
- 任务可以依赖 core，不直接导入其他任务内部代码。动作到视频走版本化产物接口。
- 通用投影/求解器不在各任务中重复实现；领域数据、模型、IK/渲染与指标由各任务维护。
- 新仓库尚未迁入算法，不要求所有合作者等待迁移完才做数据/先验接入；接口变更须与共享维护者同步。

### 实验完整性

1. 在实验前固定数据版本、split、模型 checkpoint、约束布局、容差、比较方法与预算。
2. 同时记录约束满足、质量、有效多样性、成本、失败与重试；未计算指标不能填零。
3. 指标注明单位和阶段：原始场、约束后、后处理后、网格/像素、实际执行。
4. 多 seed 需区分训练 seed、生成 seed 与场景数量；同一条件的多个样本不能假装成独立场景。DROID 的统计还应考虑 episode 内相关性。
5. 完整验证按预先定义的端到端矩阵一次执行，统一报告最终指标、产物与失败。只有具体 bug 才拆最小调试检查。
6. 数据/权重/视频放忽略目录或团队存储；版本库保留配置、脚本、环境、来源与索引。

### 一个 Application 的最终交付包

- 可独立运行的任务代码与准确命令。
- 解析后的配置、环境、代码/数据/模型版本。
- 基线与本方法的完整结果、逐样本数据和统计口径。
- 同条件多样生成展示、代表性成功与失败案例。
- 约束作用范围、数值容差、失效条件与限制。
- 一段可直接用于论文的任务定义、实验设置与结果描述。

“完成正式验证”要求上述产物齐全并经过 reviewer 复核，不以目录建立、单个 demo 或训练结束为准。
