# Historical results — Wan 1.3B input-level v2 (learned-basis Hybrid-CNF)

> **历史记录，非本次迁移重跑。** 下表数字来自 2026-11-14 原始实验的产物与报告，
> 未在本仓库迁移中重新生成；迁移时对可确定性的部分做了逐位复验（见
> [reproduction.md](reproduction.md)）。本文件不含机器路径、个人代理分工或本次未执行的
> 审阅叙述。16-scene v2 协议，区别于历史 8-scene A/C 实验。

## 设置

- 训练/测试：128 条训练轨迹 / 16 个同分布合成场景。
- 表示：10 个时间基函数 × 7 关节 = 70 维系数；锚点帧 `[0, 4, 8, 12, 13, 16]`。
- 采样：固定基与学习基各训练 6000 步；50 步 Euler 采样。
- 视频：Wan 1.3B + 既有共享 Control LoRA，20 步；17 帧，256×256，8 fps。
- 规模：4 组 × 32 条动作 = 128 条动作；× 2 个 Wan seed = 256 条视频。
- 四组：固定基 Soft、固定基 Hybrid、学习基 Soft、学习基 Hybrid。

## 主要结果

| 方法 | 六锚点位置 EPE ↓（px） | 全视频 PSNR ↑（dB） | 六锚点全部 ≤10 px ↑ |
| --- | ---: | ---: | ---: |
| 固定基 Soft | 4.418 | 22.385 | 42/64（65.6%） |
| 固定基 Hybrid | 1.911 | 22.585 | 61/64（95.3%） |
| 学习基 Soft | 4.412 | 22.386 | 39/64（60.9%） |
| 学习基 Hybrid | 1.947 | 22.588 | 61/64（95.3%） |

场景配对 bootstrap（16 场景，10000 次重采样，seed 20261114）：

| 配对对比 | Δ 锚点 EPE，95% CI（px） | Δ PSNR，95% CI（dB） |
| --- | ---: | ---: |
| 学习基 Hybrid − Soft | −2.465 [−3.068, −1.906] | +0.202 [+0.062, +0.352] |
| 固定基 Hybrid − Soft | −2.507 [−3.099, −1.957] | +0.200 [+0.064, +0.347] |
| Hybrid 内 学习基 − 固定基 | +0.036 [−0.011, +0.084] | +0.003 [−0.006, +0.010] |

## 硬约束（动作场）

两个 Hybrid 组共 64 条轨迹，经安全修复并从磁盘重载后：最大锚点误差
`8.882e-16 rad`，最大 `‖Hc − b‖` 残差 `6.661e-16`，保存的 `q` 与 `Bc` 最大差为零。

## 结论范围

- 硬等式保证作用于 17 个离散帧上的动作场 `q(t)=B(t)c`；不含连续时间碰撞保证。
- Wan RGB 的位置/PSNR 为独立测量，无对应像素级硬保证。
- 学习基相对固定基的额外收益未获统计支持（两 CI 均含 0）。
- 单训练 seed、16 个同分布合成场景；冻结 RGB 分割器为模拟器域 proxy，非生成域人工标注。
