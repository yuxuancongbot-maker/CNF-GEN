# Reproduction & migration notes — learned-basis Hybrid-CNF v2

## What was migrated vs. what was (re)run

This directory is a code migration of the already-executed 2026-11-14 input-level
v2 experiment. It is **not** a claim that the 256-video matrix was re-run during
migration.

- **Migrated (code, faithful)**: `cnf_motion` (shared), the `learned_basis_hybrid_cnf`
  package, the entry/finalize/PSNR scripts, and the data-prep/evaluator scripts
  (`prepare_v2_references.py`, `train_evaluator.py`, `generate_dataset.py`).
  Only path resolution was refactored into `config.py`; the numerical code is
  unchanged (float64 QR hard projection without ridge, SLSQP safety repair,
  scene-paired bootstrap, MSE-first PSNR).
- **Re-run during migration (validation into a fresh /tmp output)**: pure-CPU
  numerics tests, import/entry checks, the motion-level chain (data prep →
  fixed/learned training → 128-trajectory sampling + control rendering), and the
  Wan GT-replay gate (8 legacy videos). None of the pre-existing 256-video
  results were overwritten or reused as new results.
- **Not re-run**: the full 256-video Wan matrix, its scoring/statistics, and PSNR
  over those videos. These remain the pre-existing evidence summarised in
  [historical_results_20261114.md](historical_results_20261114.md).

## Resource prerequisites (which binaries are needed and how to get them)

| Resource | How to obtain | Regenerable here? |
|---|---|---|
| Base dataset (128 + 16 scenes) | `scripts/generate_dataset.py` | Yes (deterministic; needs `pybullet_data` Panda URDF) |
| 16 v2 eval references + targets | `scripts/prepare_v2_references.py` | **Partial** — scenes 8–15 are generated by the script; scenes 0–7 are **reused from the legacy 8-scene v2 references** (`CNF_V2_OLD_V2_COND`), which are **not regenerable from this repo** |
| Frozen RGB evaluator (`SmallUNet` step 2000) | `scripts/train_evaluator.py` | Yes (train + calibrate on episodes 0–127) |
| Wan 1.3B Control model + 1k-step LoRA | external (team storage) | No — model weights and LoRA training are **not migrated** |
| VideoX-Fun checkout | external; pin its revision | No |
| 8 GT-replay control/video pairs | `CNF_V2_BASE_1_3B` (team storage) | **No** — pre-existing artifacts, not regenerable here |

The scripts refuse to overwrite existing outputs unless `--force` is passed
(`generate_dataset.py`, `prepare_v2_references.py`, `train_evaluator.py`,
`--stage train`).

## Staged reproduction (real, copyable commands)

All commands run from the repository root, after installing
`pip install -e '.[motion]' -e 'experiments/learned_basis_hybrid_cnf[wan]'` and
setting the `CNF_V2_*` configuration (see the experiment README).

```bash
# 0. base dataset
python experiments/learned_basis_hybrid_cnf/scripts/generate_dataset.py \
  --output datasets/pickplace256 --count 128 --seed 0
python experiments/learned_basis_hybrid_cnf/scripts/generate_dataset.py \
  --output datasets/pickplace256_eval --count 16 --seed 1

# 1. v2 references + targets (needs CNF_V2_OLD_V2_COND for scenes 0-7)
python experiments/learned_basis_hybrid_cnf/scripts/prepare_v2_references.py

# 2. frozen RGB evaluator
python experiments/learned_basis_hybrid_cnf/scripts/train_evaluator.py

# 3. train fixed + learned bases (also does the 128-train v2 repair into CNF_V2_OUT)
python experiments/learned_basis_hybrid_cnf/scripts/run_learned_basis_hybrid_cnf.py --stage train

# 4. sample 128 trajectories + render semantic controls (CNF / safety / certificates)
python experiments/learned_basis_hybrid_cnf/scripts/run_learned_basis_hybrid_cnf.py --stage motion

# 5. Wan 1.3B + LoRA: 256-video matrix (GPU; the expensive step)
python experiments/learned_basis_hybrid_cnf/scripts/run_learned_basis_hybrid_cnf.py --stage video

# 6. scoring (frozen evaluator) and statistics (scene-paired bootstrap)
python experiments/learned_basis_hybrid_cnf/scripts/run_learned_basis_hybrid_cnf.py --stage score
python experiments/learned_basis_hybrid_cnf/scripts/run_learned_basis_hybrid_cnf.py --stage stats

# 7. CPU-only PSNR over the generated videos
python experiments/learned_basis_hybrid_cnf/scripts/psnr_eval.py
```

`--run-all` is shorthand for steps 4–6 + report writing and **does not** train
(step 3) and **does not** compute PSNR (step 7); those must be run explicitly.
