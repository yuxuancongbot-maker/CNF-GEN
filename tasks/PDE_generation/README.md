# CNF 在流体/PDE 场上的硬约束生成

本项目把 CNF（Constrained Neural Fields）应用到流体/PDE 场，验证硬约束投影在静态与动态 PDE 任务上的表现。方法统一为：**场 = Σ 系数 × 基 → flow matching 条件生成系数 → CNF 投影 Hc=b**，对比 Soft与 Hybrid。

数据来自公开数据集 PDEBench（DaRUS，10.18419/darus-3855）。

| 任务 | 本地文件名 | PDEBench 原始文件 | 形状 | 大小 |
|---|---|---|---|---|
| Darcy | `datasets/pde/darcy.h5` | 2D_DarcyFlow_beta0.01_Train.hdf5 | 10000 × 128 × 128 | 1.3 GB |
| Burgers | `datasets/pde/burgers.nu0.01.h5` | 1D_Burgers_Sols_Nu0.01.hdf5 | 10000 × 1024 × 201 | 8.2 GB |

Darcy 文件包含 `tensor`（压力场）与 `nu`（渗透率场）两个数据集；Burgers 文件包含 `tensor`（时空场 u(x,t)）。把原始文件重命名为上面的本地文件名后放到 `datasets/pde/` 下即可。

## 三、任务与配置

### 3.1 Darcy（静态 PDE）

| 项 | 值 |
|---|---|
| 场 | 压力场 p(x,y)，128×128 |
| 基 | 二维 Fourier，K=8，共 289 个系数 |
| 约束 | 20 个边界点（每边 5 个）+ 180 个内部点（12×15 网格），共 200 点 |
| 约束矩阵条件数 | 85 |
| 模型 | MLP，隐层 512，lr 1e-3，AdamW，余弦退火，50000 步 |
| 软约束权重 | 20.0 |
| 训练/测试 | 9000 / 1000 |

### 3.2 Burgers（动态 PDE）

| 项 | 值 |
|---|---|
| 场 | 时空场 u(x,t)，1024 空间 × 201 时间步，粘度 0.01 |
| 基 | 空间 Fourier K_x=32 共 65 个空间模 × 时间 Legendre K_t=20 共 20 个时间模，总计 1300 个系数 |
| 约束 | 空间 50 个随机点 × 时间 20 个均匀帧，共 1000 点，少于 1300 个系数，欠定 |
| 模型 | MLP，隐层 2048，lr 1e-4，AdamW，余弦退火，100000 步 |
| 投影正则化 | 截断 SVD，rcond = 1e-3 |
| 软约束权重 | 20.0 |
| 训练/测试 | 9000 / 100（评估 100 场 × 20 样本） |

空间点用随机而非均匀，是为了避开 Fourier 基在均匀点上的混叠；时间点用 Legendre 基，均匀取即可。

## 五、实验结果

三个评估指标：

- **约束残差**：生成场在观测点上的值与观测值的最大偏差，衡量约束满足程度；
- **相对均方误差**：生成场与真实场逐点均方误差除以真实场能量，衡量重建质量；
- **物理残差**：把生成场代入控制方程算出的残差，衡量物理一致性。

### 5.1 Darcy

| 指标 | Soft | Hybrid |
|---|---:|---:|
| 约束残差 | 7.05e-3 | 1.33e-9 |
| 相对均方误差 | 1.138 | 5.61e-3 |
| 物理残差 | 6.65 | 9.45 |

### 5.2 Burgers

| 指标 | Soft | Hybrid |
|---|---:|---:|
| 约束残差 | 0.259 | 0.082 |
| 相对均方误差 | 2.00% | 1.03% |
| 物理残差 | 11.2 | 47.4 |

## 六、结果分析

### 6.1 核心结论：CNF 硬投影低频稳定、高频放大

投影公式 c* = c + H†(b − Hc)，H† = V Σ⁻¹ Uᵀ。Σ⁻¹ 里的 1/σ 是放大系数：

- 低频方向，σ 大，1/σ 小，投影温和，稳定精确；
- 高频方向，σ 小，1/σ 巨大，投影放大甚至发散。

两组实验共同印证：

| 实验 | 场 | 低频 | 高频 |
|---|---|---|---|
| Darcy | 平滑压力场 | 稳定，重建误差 5.6e-3 | 出现 k=8 高频尖峰，物理残差略升 |
| Burgers | 含激波场 | 重建误差降到 1.03% | 物理残差升到 47.4 |

要复原的场本身含有高频分量（Burgers 的激波、Darcy 的高频部分）。由于观测点数量有限，这些高频特征无法被充分提取；在硬投影拟合锚点时，提取不到的高频特征就表现为高频噪声，因此 Hybrid 的高频物理残差比 Soft 大。

进一步看，Soft 的高频来自 FM 从训练数据学到的先验，是合理的激波；Hybrid 为了精确拟合锚点，对锚点"看不见、也约束不住"的高频部分做了盲目且较大的改动，于是把合理高频改成了噪声。

### 6.2 适用边界

CNF 硬投影适用于观测点能分辨的平滑场；对含高频的场加稀疏观测，会因高频欠定而放大噪声。这正是"有限点约束不等于全域物理保证"的数学来源。
