# 动作生成与具身 Agent

**目标：** 给定初始状态和稀疏动作关键点，生成多条满足指定条件的连续动作轨迹。后续可将轨迹采样成 action chunk，供具身 Agent 调用。

**约束示例：** 指定时刻的关节位置；后续可研究速度等导数条件。评估轨迹质量、多样性、限位与碰撞等指标。

**当前状态：** 原工作区已有动作场和 learned-basis Hybrid 实验；本目录仍是骨架，代码尚未迁入。Agent 技能和闭环执行尚待实现。

**从这里开始：** 查看 [README](README.md) 与 [任务清单](TASKS.md)，迁入已有动作生成和评测代码，并与共享的 [CNF 方法](../../src/gcnf/)对接。向视频模块提供版本化的动作产物。

约束满足不等于机器人实际执行成功。开发协作遵循[仓库开发者注意事项](../../AGENT.md)。
