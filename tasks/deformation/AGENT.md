# 形变场生成

**目标：** 对已有物体生成多个合理的连续形变，同时满足用户指定的局部控制。

**约束示例：** 固定部分 handle，或指定某些位置的位移；后续可研究局部导数约束。评估控制点误差、形变质量、多样性和翻折情况。

**当前状态：** 候选应用；本目录是骨架，尚无应用实现或实验结果。

**从这里开始：** 查看 [README](README.md) 与 [任务清单](TASKS.md)，选择形变数据和生成模型，再将 handle 约束接入共享的 [CNF 方法](../../src/gcnf/)。

局部位移满足不自动保证全局可逆、局部刚性或体积保持。开发协作遵循[仓库开发者注意事项](../../AGENT.md)。
