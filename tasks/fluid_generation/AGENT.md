# 流体场生成

**目标：** 生成合理且多样的流体速度场，在保持选定结构性质的同时满足给定观测。

**约束示例：** 测试时指定若干位置的速度；可研究与结构化无散度表示或边界条件的组合。评估观测误差、无散度性质、场质量和多样性。

**当前状态：** 候选应用；本目录是骨架，尚无应用实现或实验结果。

**从这里开始：** 查看 [README](README.md) 与 [任务清单](TASKS.md)，选择流场数据和生成模型，设计不破坏既有结构的 [CNF 方法](../../src/gcnf/)接入。

有限点上的约束不自动保证全域性质；结构保证及其条件需要单独说明。开发协作遵循[仓库开发者注意事项](../../AGENT.md)。
