# PDE 场生成

**目标：** 对具有不确定性的物理问题生成连续场，并满足指定的初始、边界或适用的守恒条件。

**约束示例：** 固定若干初始值或边界值，或施加适用的线性积分条件；同时单独评估控制方程残差、生成质量和多样性。

**当前状态：** 候选应用；本目录是骨架，尚未选定具体 PDE、数据或生成模型，也没有应用实验结果。

**从这里开始：** 查看 [README](README.md) 与 [任务清单](TASKS.md)，先选择具体问题并说明随机性来源，再接入共享的 [CNF 方法](../../src/gcnf/)。

满足有限点初边值不等于严格满足整个 PDE。开发协作遵循[仓库开发者注意事项](../../AGENT.md)。
