# 3D 形状补全

**目标：** 给定部分观测，生成多个合理的完整三维形状，同时保持给定的表面条件。

**约束示例：** 指定表面点的隐式场值为零，并在可靠法线已知时约束对应的场梯度。评估约束误差、形状质量和生成多样性。

**当前状态：** 候选应用；本目录是骨架，尚无应用实现或实验结果。

**从这里开始：** 查看 [README](README.md) 与 [任务清单](TASKS.md)，选择数据和隐式场生成模型，再接入共享的 [CNF 方法](../../src/gcnf/)。

指定点的约束不自动保证整体 SDF 性质或拓扑正确。开发协作遵循[仓库开发者注意事项](../../AGENT.md)。
